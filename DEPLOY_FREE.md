# Бесплатный запуск без карты (Render + GitHub) — коротко и по шагам

Что бот теперь делает сам:
- отдаёт и сайт, и API с одного адреса — ничего вписывать в `index.html` не надо;
- сам узнаёт свой адрес на Render (`SHOP_WEBAPP_URL` вписывать не обязательно);
- пингует сам себя (`KEEPALIVE=true`), чтобы бесплатный хостинг не усыплял его;
- сам закрывает оплаченные заказы CryptoBot в фоне (раз в ~45 сек), даже если клиент закрыл приложение;
- каждые N часов присылает админу в Telegram **файл-копию базы**; после перезапуска хостинга отправьте этот файл боту с подписью `/restore` — база вернётся.

## Шаг 1. Токены (5 минут)
- `BOT_TOKEN` — @BotFather → /newbot
- `CRYPTO_BOT_TOKEN` — @CryptoBot → Crypto Pay → My Apps → Create App
- `ADMIN_IDS` — ваш ID из @userinfobot

## Шаг 2. GitHub (бесплатно)
1. Зарегистрируйтесь на github.com → New repository → название `starlify`, тип **Private**.
2. Нажмите «uploading an existing file», перетащите **всё содержимое** папки StarlifyShop (bot, webapp, Procfile, requirements.txt и т.д.), Commit.
   Файл `.env` загружать нельзя (токены хранятся только на хостинге).

## Шаг 3. Render (по обзорам — без карты)
1. render.com → Sign up через GitHub.
2. New + → **Web Service** → выберите репозиторий `starlify`.
3. Поля:
   - Language: **Python 3**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `cd bot && python main.py`
   - Instance Type: **Free**
   - Advanced → Health Check Path: `/api/health`
4. Environment Variables (Add):
   | Имя | Значение |
   |---|---|
   | BOT_TOKEN | токен бота |
   | CRYPTO_BOT_TOKEN | токен CryptoBot |
   | ADMIN_IDS | ваш ID |
   | KEEPALIVE | true |
   | BACKUP_HOURS | 1 |
   | PYTHON_VERSION | 3.12.3 |
5. Create Web Service. Через пару минут в логах появится `Система StarlifyShop запущена.`
6. Откройте выданный адрес `https://название.onrender.com/api/health` → `{"ok": true}`.
7. В Telegram: `/start` → кнопка «🛍 Магазин». Если кнопки нет, добавьте переменную `SHOP_WEBAPP_URL` = ваш адрес onrender.com и перезапустите.

Если Render попросит карту — условия изменились, тогда см. альтернативу ниже.

## Важно знать (честно)
- **Диск на бесплатном Render временный.** При перезапуске/обновлении база пропадает. Поэтому бот шлёт вам копии базы. После перезапуска: отправьте последний файл боту с подписью `/restore`. Заказы между последней копией и перезапуском потеряются — поэтому `BACKUP_HOURS=1`.
- Render может перезапускать бесплатные сервисы и менять условия, гарантий нет. Бесплатного без риска для магазина с деньгами не бывает; когда пойдут реальные продажи — перейдите на платный тариф или VPS (инструкция в `DEPLOY_GUIDE.md`).
- Бесплатных 750 часов в месяц хватает на один сервис, работающий круглосуточно.
- Реквизиты карты, курс Stars и цены Premium задаются в настройках бота (админ-команды).

## Реквизиты, цены, разделы витрины, пополнения

**Карта (обязательно!).** Пока карта не задана, оплата и пополнение картой отключены, а админу приходит предупреждение.
В Render → Environment добавьте `CARD_NUMBER` (например `5375 4141 0000 0000`) и `CARD_NAME` (имя владельца) — сервис перезапустится сам.
Эти переменные применяются при каждом старте, поэтому не пропадут при очистке базы. Опционально: `STARS_RATE`, `PREMIUM_3M`, `PREMIUM_6M`, `PREMIUM_1Y`.

**Скрыть/показать разделы Mini App** (например, NFT) — командами админа в боте:
`/sections` — список, `/hide nft` — скрыть, `/show nft` — вернуть, можно несколько: `/hide nft ton reviews`.
Ключи: `stars, premium, ton, nft, reviews, channel, support`.
Чтобы раздел был скрыт всегда (даже после очистки базы), добавьте переменную `HIDE_SECTIONS=nft`.

**Пополнение баланса.**
- Картой: клиент видит реквизиты → переводит → жмёт «Я оплатил» → вам приходит сообщение с кнопками **«✅ Зачислить на баланс» / «❌ Отклонить»**. Клиенту бот пишет результат.
- CryptoBot: счёт создаётся автоматически, баланс зачисляется сам (кнопка «Проверить» или фоновая проверка).
- Баланс можно тратить на заказы (способ оплаты «С баланса»).
- Вручную: `/credit ID сумма` (отрицательная сумма — списание).

**Вывод средств.** Сумма сразу резервируется (списывается с баланса). Вам приходит заявка с кнопками **«✅ Выплачено» / «❌ Отклонить (вернуть на баланс)»**.

**Заказы клиента.** Теперь «📦 Мои заказы» — на главном экране Mini App (с числом активных заказов) и на экране после оплаты. Статусы обновляются сами каждые 15 секунд.
